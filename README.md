# Spacify

**Spacify** is a simple cool encyclopedia that talks about space and it includes things like the planets and it is a great learning resource.

It talks about many things which includes the follow:

- Space meaning
- The Sun
- The Moon
- The Planets
- Stars
- Galaxies
- Black Holes
- Astronauts
- Facts

Extra things that I added:

- Contents
- Sources
